# YOUR DESTINY — Telegram WebApp / GitHub / Cloudflare

## Структура
Файлы проекта лежат непосредственно в корне:
- `index.html`
- `style.css`
- `app.js`
- `promo-config.js`
- `splash-cover.png`

## Языки
Поддерживаются 6 языков интерфейса:
- Русский
- English
- Español
- Português
- Deutsch
- Français

При первом запуске внутри Telegram язык определяется по `language_code` пользователя:
- русский и языки СНГ → русский;
- испанский → Español;
- португальский → Português;
- немецкий → Deutsch;
- французский → Français;
- английский и любой другой язык → English.

После ручного выбора язык сохраняется локально.

## Капсула Времени
Дата первого входа сохраняется в `localStorage` один раз и отображается с точностью до часов и минут.

## Промокод
Менять код нужно только в `promo-config.js`:
```js
window.ACTIVE_PROMO_CODE = 'DESTINY2026';
```

Срок уже активированного VIP не сбрасывается при смене кода.
