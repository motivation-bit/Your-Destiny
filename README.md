# YOUR DESTINY — Telegram WebApp

## Запуск
Загрузите содержимое проекта на GitHub/Cloudflare Pages или другой HTTPS-хостинг и укажите URL в Telegram WebApp.

## Промокод
Откройте `promo-config.js` и измените только:

```js
window.ACTIVE_PROMO_CODE = 'DESTINY2026';
```

При замене кода уже активированный 30-дневный VIP не сбрасывается: его первоначальная дата окончания сохраняется в `localStorage`. После окончания текущего VIP активировать можно только код, который сейчас указан в `promo-config.js`.

## Язык
При запуске внутри Telegram используется `language_code` пользователя. Поддерживаются русский и английский. Если язык пользователя другой, автоматически выбирается английский.

## Дата первого входа
При первом запуске сохраняется `first_visit_at` в `localStorage`. В разделе «Капсула Времени» отображается число, месяц и год первого входа.

## Темы
Порядок тем:
1. Королевский Пурпур
2. Полночный Сапфир
3. Багровый Занавес
4. Изумрудный Лес
5. Янтарные Сумерки
6. Калейдоскоп

«Калейдоскоп» плавно анимирует переходы между всеми основными цветовыми палитрами.
